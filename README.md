# Little List

A simple to-do list made with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern web browser. No installation or server is required.

Type a task and select **Add task** (or press Enter). Use its checkbox to mark it complete or incomplete, and select **Delete** to remove it. Tasks are saved in your browser's local storage, so they remain when you reopen the page in the same browser. If browser storage is unavailable, the app displays a warning and tasks last only for the current page session.
